Architecture map

Hot path: client request crosses API Gateway, enters Task Svc, and writes to PostgreSQL. Notify Svc and Redis are optional background paths.

Key files

src/gateway/router.ts route Main API router — maps endpoints to service handlers.
src/services/task/handler.ts handler Task CRUD logic and optimistic update coordination.
src/services/auth/middleware.ts middleware JWT validation and role-based access control.
src/db/schema.prisma schema Database schema definition and migrations.

Boundaries

Trust boundary

All requests crossing from client to API gateway are authenticated via JWT. Internal service-to-service calls use mTLS.

Persistence boundary

Only Task Svc writes to PostgreSQL. Other services read via a replicated read-only connection.

Risks

Single point of failure: API Gateway No circuit breaker on Notify Svc Auth Svc: well-tested, stable
